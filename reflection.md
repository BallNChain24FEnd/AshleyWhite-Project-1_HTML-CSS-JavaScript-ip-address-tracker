# IP Address Tracker — Project Reflection

For this project, I built an IP Address Tracker using HTML, CSS, and JavaScript. The goal was to allow users to search for an IP address or domain and view location information on an interactive map.

I started by organizing my files and creating the HTML structure. Then, I used CSS and Flexbox to design the desktop layout. I also used media queries to make the website responsive on mobile devices.

My biggest challenges involved connecting the IPify API, setting up Vercel, and displaying the Leaflet map. I experienced errors with my API key, development server, and map positioning. I worked through these problems by checking terminal messages, using browser developer tools, and testing my code.

I learned more about fetch, async/await, event listeners, and error handling. I also practiced using Git commits to track changes and GitHub to store my project. These experiences helped me understand how different technologies work together.

In the future, I would improve the map layout, strengthen input validation, and explore more interactive features. I also want to become more comfortable working with APIs independently.

Overall, this project strengthened my JavaScript skills and taught me the importance of testing, debugging, and problem-solving.
