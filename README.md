# IP Address Tracker

## Project Overview
This project is an IP Address Tracker built with HTML, CSS, and JavaScript. Users can search for an IP address or domain and view its approximate geographic location on an interactive map.

This project was completed as part of the Per Scholas HTML, CSS, and JavaScript assessment.

## Features
1. Search for IP addresses and domains.
2. Display IP address, location, timezone, and ISP.
3. Show geographic locations using an interactive Leaflet map.
4. Responsive desktop and mobile layouts.
5. Input validation and error handling.

## Technologies Used
- HTML5
- CSS3 and Flexbox
- JavaScript
- IPify Geolocation API
- LeafletJS and OpenStreetMap
- Vercel for deployment
- Git and GitHub for version control

## How to Run
1. Download or clone this repository.
2. Create a free IPify Geolocation API account.
3. Add `IPIFY_API_KEY` to a local `.env.local` file.
4. Run the project using `vercel dev`.
5. Open the local URL shown in the terminal.

The API key is kept private using environment variables and a serverless function.
